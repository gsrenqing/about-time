# 磨砂效果（壁纸虚化）问题归因与方法论

> 项目：About Time 桌面时钟挂件（C# WinForms，.NET 4.x，分层窗口 UpdateLayeredWindow）
> 版本跨度：1.6 → 1.8.4（2026-11）
> 用途：任何「桌面/壁纸/图层合成 + 实时重绘」类功能的可复用参考。

---

## 0. 最终形态（先给结论）

磨砂卡片的成品 = **不透明的「糊壁纸 + 主题色」层**：

```
整幅壁纸（原生 DIB 抓取）
  → 1/4 降采样缓存（910×533 ≈ 1.9MB，带指纹判据）
  → 按窗口位置裁剪 + 外扩 2r 消边界 → 盒式模糊 r 次
  → 向主题基色收缩：out = blur*(1-a) + base*a      （a = 玻璃浓度）
  → 圆角裁剪铺底 → 只描边 + 26 级薄主色 → 内容
```

配方要点：**磨砂层永远整块铺底、绝不按 alpha 往下压**；「背景透明度」语义是
玻璃浓度 aEff = a + (1-op)×(1-a)，任何档位都不掺清晰像素（这是 Windows acrylic 的做法）。

半径阶梯（1/4 图像素，等效全分辨率约 ×4）：7.0（1.7.2）→ 5.6（1.8.0）→ 3.9（1.8.1）
→ 3.1（1.8.2）→ **2.5（1.8.4，整数舍入落到下限 2）**。再往下只能改采样管线，不是改数字。

## 1. 坑点总表

| # | 现象 | 根因 | 解法 | 版本 |
|---|------|------|------|------|
| 1 | 看不出模糊 | 把"清晰的桌面原图"按 (1-op) 掺回磨砂层，op 低时清晰成分占主导 | op 只调玻璃浓度，永不掺清晰像素 | 1.7 |
| 2 | 大幅变白 | 平均亮度定标到固定值（钳 ±60），亮壁纸压不回去 | 删掉定标，改向主题基色收缩 | 1.7 |
| 3 | 边缘拖影 | 盒式模糊对采样窗口边界做 clamp | 采样窗口外扩 2r，裁回原框 | 1.7 |
| 4 | 换壁纸后图案永不变 | 缓存判据只有"宿主句柄+尺寸"；失效事件在分层窗口下不可靠；开关磨砂只清裁剪块 | 壁纸指纹 + 秒级轮询 + 显式失效三层兜底 | 1.8.2 |
| 5 | 弹出层没有磨砂 | 弹出窗走另一条绘制链，只有半透明实心刷 | 弹出卡接入同一配方，带屏幕位置参数 + 位置感知缓存 | 1.8.3 |
| 6 | 半径降不下去 | 整数量化 + Math.Round 银行家舍入 + 下限钳 2 | 认清量化边界；要更清改采样（1/8 图）而非数字 | 1.8.4 |
| 7 | 长跑内存垫高 10~20MB | 整幅抓图 31MB 落托管大对象堆（LOH），轮播反复分配 | 原生 DIB 抓取 + StretchBlt，DeleteObject 立即归还 | 1.8.4 |
| 8 | CreateDIBSection 一直失败 | BITMAPINFOHEADER 的 biPlanes/biBitCount 写成 int（实际 short），头错位 | GDI 结构体一律逐字段抄工程内已验证定义 | 1.8.4 |
| 9 | 抓图 DC 得到一片空白/泄漏 | Graphics 的 Hdc 误配 ReleaseDC（应 ReleaseHdc）；直接把 GDI+ 位图喂 UpdateLayeredWindow 会全空白 | Hdc 只配 ReleaseHdc；先画进独立 PArgb 位图再拷进 DIB 推送 | 1.6 |
| 10 | 回归自检假 FAIL | 定时器消息合并导致指纹基线登记落在改动之后 | 测试先显式同步登记基线，再改动再核对 | 1.8.2 |

## 2. 关键坑点展开

### 2.1 「看不出模糊」：alpha 语义错误（最隐蔽的一坑）

1.6 的做法：磨砂层按 `ColorMatrix` 把 alpha 压到 op，分层窗推送后与桌面**混合**。
后果：op 越低清晰桌面成分越多，模糊被天然稀释——用户"开到 50% 和没糊一样"。

**判据**：磨砂是"玻璃"，语义应是"浓度"而非"不透明度"。浓度低 = 玻璃变淡（透更多主题色方向），
而不是"露出更多清晰背景"。修正后任何 op 档位模糊感一致，op 只改颜色浓淡。

### 2.2 「换壁纸不跟随」：缓存失效三重失效（1.8.2 主案）

现象：换壁纸、拖拽、关掉磨砂再打开，模糊图案全部停留在第一张壁纸。用户描述
"第一个壁纸被截图模糊后失去反应"——完全正确。

三层根因（缺一复现不出"关掉再开也没用"）：
1. 缓存判据 `_host == host && _ww == ww && _hh == wh`：换壁纸时宿主 WorkerW 句柄与
   屏幕尺寸**都不变**，缓存永远命中；
2. 唯一失效入口挂在 `SystemEvents.UserPreferenceChanged(Desktop)`，该事件在
   分层窗口/UpdateLayeredWindow 场景**并不总会送达**；
3. SetBlur 只清挂件自己裁好的那块（FrostInvalidate），没碰整幅缩略图。

**解法：指纹 + 轮询 + 显式失效**
- 指纹 = SPI_GETDESKWALLPAPER 路径 + 文件 LastWriteTimeUtc + 字节数。幻灯片/Windows
  聚焦改写 TranscodedWallpaper，路径不变但文件必被重写，同样能识别；取不到返回 "?" 不参与判断（防反复重抓）；
- 看门狗每 ~1 秒核对一次指纹（每次只读一个文件属性），变化即"作废整幅缓存→重抓→重绘"；
- 开关磨砂 / 自检路径显式失效，并重置轮询基线（防二次重抓）。

**教训**：任何"状态变了但事件不一定通知你"的场景，用**廉价指纹轮询兜底**，
事件只当加速器不当正确性保证。

### 2.3 「弹出层没有磨砂」：同一功能两条绘制链（1.8.3）

弹出日历是独立分层窗口，卡片底在它自己的 RenderCalCard 里画，只有一句
`SolidBrush(P.Card)`（P.Card 自带 alpha = 透明度）——观感半透明、没有磨砂；
且主窗拖动时它只改 Bounds 不重画。

**解法**：RenderCalCard 增加屏幕位置重载；磨砂开启且位置在屏时 Grab 窗口身后那块壁纸，
同一配方铺底（圆角裁剪 + 描边 + 26 级薄主色），抓不到/离屏退回实心（与主窗降级一致）；
缓存 key = 位置+尺寸+样式+缩放+透明度；主窗失效时联动作废；拖动后立刻重画。

**教训**：一个视觉特性若有多个绘制入口，**特性必须下沉成可复用的绘制配方**，
否则每条链都会各缺一块。离屏快照/测试路径传 int.MinValue 位置，自然走降级。

### 2.4 整幅抓图从托管位图改为原生 DIB（1.8.4）

`new Bitmap(ww, wh)` 接 PrintWindow 的 31MB 落在 LOH 上，壁纸轮播每换一张就来一次，
长跑 LOH 碎片把私有内存垫高十几 MB。改为：
CreateDIBSection(ww×wh 32bpp) → PrintWindow 进 DIB 的 DC → StretchBlt(HALFTONE) 缩到
1/4 托管位图 → DeleteObject 立即归还。托管堆全程只有 ~1.9MB 缓存进出。

HALFTONE 降采样质量足够：磨砂输入还要过盒式模糊，无细节损失
（实测 op50 纹理保留 2%、op100 0%，与旧路径同档）。

### 2.5 GDI 结构体逐字段错位（1.8.4 排错实录）

BITMAPINFOHEADER 的 biPlanes/biBitCount 是 **short**；写成 int 后整个头错位，
CreateDIBSection 一直失败、磨砂**静默退回实心卡**——若没有自检的 LastLog
（"CreateDIBSection failed"）当场抓住，用户只会看到"磨砂又没了"。

**规矩**：新增 GDI 结构体一律先抄工程内已验证的定义；抓取失败必须写 LastLog 并有自检读它。

### 2.6 半径的整数量化边界（1.8.4）

`r = Max(2, (int)Math.Round(2.5 × scale))`：
- scale=1.0 时 Math.Round(2.5)=2（**银行家舍入**，不是四舍五入）；
- r<2 被下限钳掉。所以"再降 20%"在数字上可行，观感上已到整数下限。

**教训**：调参前先算清量化阶梯；文档里记"参数→观感"的实测对应表，否则每轮都是盲调。

## 3. 指标口径（验收怎么量）

| 指标 | 定义 | 判读 |
|------|------|------|
| 纹理保留率 | 卡片 HF（高频能量）/ 壁纸 HF | 真磨砂应 <10%（op50 档）；同时壁纸 HF 要 >1，壁纸本身平滑时该指标无意义 |
| 白化量 | 卡片均值 − 壁纸均值 | 大幅为负/正都异常；应收敛到主题色附近 |
| 换壁纸重抓 | CaptureCount 增量 | 指纹改动时间戳模拟换图，确定性 PASS/FAIL |
| 抓取日志 | op/t/r/host/rect/cache | 每次抓取都落日志，排错第一现场 |

## 4. 可复用检查清单

- [ ] "磨砂/玻璃"语义 = 浓度；任何 alpha 混合不得把清晰原图掺回；
- [ ] 亮度处理用"向基色收缩"，不用定标；
- [ ] 盒式模糊采样外扩 2r 消边界；
- [ ] 缓存判据必须包含**内容指纹**，不能只靠句柄/尺寸；
- [ ] 系统事件不可靠时加廉价指纹轮询兜底；取不到指纹时"不动作"而非"反复动作"；
- [ ] 同一视觉特性只有一个绘制配方，多窗口/弹层全部接入；
- [ ] 磨砂抓不到（离屏/锁屏/虚拟桌面）必须降级为实心卡，绝不空白；
- [ ] 大块抓图用原生 DIB，不进托管 LOH；GDI 结构体逐字段抄已验证定义；
- [ ] 每次抓取写 LastLog；自检读日志做确定性断言；
- [ ] 调参先算量化阶梯（舍入方式、下限），并维护"参数→观感"阶梯表；
- [ ] 测试改动环境（时间戳/指纹）后必须还原；先登记基线再改动。
